# 時間記帳

用記帳的方式記錄一天中每個時段做了什麼，對時間更有意識、減少滑 SNS 的時間。
Android App（Capacitor + React + TypeScript），資料全部存在手機本機。

## 安裝到手機（Pixel）

1. 在手機瀏覽器打開本 repo 的 **Releases → 「最新 APK」**，下載 `time-ledger.apk`
   （每次推送程式碼，GitHub Actions 會自動建置並更新這個 Release）。
2. 打開下載的檔案；第一次會要求允許「安裝不明應用程式」，允許瀏覽器即可。
3. 開啟 App →「設定」→ 允許通知 → 按「傳送測試通知」確認提醒正常。
4. 建議：系統設定 → 應用程式 → 時間記帳 → 電池用量 → 選「不受限制」。

之後的新版本直接下載覆蓋安裝即可，資料會保留（所有 APK 用同一把簽章金鑰）。
⚠ 不要先解除安裝再裝，解除安裝會刪除本機資料。保險起見請定期在「設定 → 備份」匯出 JSON。

## App 內更新

設定 →「App 更新」可以手動檢查；開啟「自動檢查更新」後，打開 App 時（每 6 小時最多一次）會檢查
GitHub 上的最新 APK，有新版就在畫面上方提示。按「立即更新」會下載 APK 並開啟系統安裝畫面。
第一次會要求允許「時間記帳」安裝應用程式。Android 不允許自行安裝的 App 靜默更新，最後一步需要按「更新」。

每次建置的更新說明來自 `RELEASE_NOTES.md`。

## 提醒機制

- 使用 `@capacitor/local-notifications`，由 Android 系統的 AlarmManager（`setExactAndAllowWhileIdle`）排程，
  App 關閉、離線、省電休眠時都會準時觸發；重開機後會自動恢復。
- 一次排好未來 30 天、每天三則（預設 12:30／18:00／22:30），每次開 App 會自動補排。
- 每則提醒回顧「上一個提醒到這個提醒」之間的時段（第一個從 00:00 起，最後一個到午夜）。
- 若在提醒時間前已經把該時段記完，當天那則就不會發出。
- 點通知會直接進入該時段的補記畫面，列出尚未記錄的空白區段。

## 開發

```bash
npm install
npm run dev        # 瀏覽器預覽（手機尺寸檢視），提醒功能只在 App 上運作
npm test           # 單元測試
npm run build && npx cap sync android   # 同步到 Android 專案
```

建置 APK 需要 Android SDK 與 JDK 21：`cd android && ./gradlew assembleDebug`；
或直接推送到 GitHub 由 `.github/workflows/android.yml` 建置。
